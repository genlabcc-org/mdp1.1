# Makka Design Pakka 1.1

Official website for **Makka Design Pakka 1.1**, an initiative by Uncommon Institute of Design (UID) & MARK9.

## Tech Stack
- React 19
- Vite
- Vanilla CSS

## Getting Started

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
